# Mark records

Each mark has a stable page at its eight-digit serial number:

`https://tmterminal.merchbase.co/60146682`

The page shows owner, classes, goods and services, and status history. A registration number appears only after the USPTO registers the mark.

Open the official USPTO TSDR record from the mark page when you need the government file. Trademark Terminal is not a copy of TSDR.

Look up a mark without browsing:

```sh
tt get --serial 60146682
tt get --registration 0146682
```
