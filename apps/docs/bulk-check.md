# Bulk Check

Enter one phrase per line. Each phrase is a Screen Query. You get live exact and live partial counts for every line in one Data Version.

Each line returns a live exact count and a live partial count. Open a line to see the Search Marks hits behind those numbers.

Bulk Check is a signed-in website tool. The HTTP `screen` procedure (named queries) is the batch form. `tt screen` and MCP `tmterminal_screen` take one complete listing text, not a line list.
