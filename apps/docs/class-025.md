# Class 025 and what we do not do

V1 materializes complete details for International Class 025 (clothing, footwear, headgear). That is the print-on-demand class this service is for.

Other classes are not the product. Do not assume a quiet Class 025 result means the word is clear everywhere.

Trademark Terminal does not:

- Give legal advice or a clearance opinion
- File, watch, or prosecute applications
- Replace USPTO TSDR
- Expose operator source repair
- Offer anonymous search

Annual and daily USPTO packages are how files arrive. They are not separate datasets you can query.
