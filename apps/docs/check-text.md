# Check Text

Paste listing copy. Trademark Terminal finds live marks that appear as exact phrases in that text.

Highlighted passages are navigation, not a verdict. Selecting a passage filters the result list to the marks behind it.

Check Text is a signed-in website tool. The same job in automation is `tt screen` or `client.trademarks.screen`: each matching live trademark once, without source positions. The richer HTTP `match` call keeps named documents and occurrence spans.

Input is limited. Over-long text is rejected, not truncated.
